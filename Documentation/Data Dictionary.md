# Data Dictionary

The [Data Dictionary](https://docs.google.com/spreadsheets/d/1cVJE4g9CotHjt43zmOT1h58f4x3OSnPP1L0T1cM4K8Q/edit?usp=sharing) provides a clear reference for the fields used in this project, including each field's name, definition, and role in the dataset. It helps make the analysis easier to understand by showing what each column represents and how it should be interpreted. This is important because clear field definitions reduce confusion, support consistent analysis, and make it easier for others to review or continue working with the data.
